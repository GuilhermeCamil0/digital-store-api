# Projeto Back-end - Digital Store (Geração Tech 4.0)

API RESTful desenvolvida em Node.js com Express, Sequelize, MySQL, autenticação JWT, testes com Jest e documentação via Swagger.

## Tecnologias Utilizadas
- Node.js & Express.js
- MySQL & Sequelize ORM (com Migrations)
- JWT (JSON Web Token) & Bcrypt
- Dotenv & Nodemon
- Jest & Supertest
- Swagger UI
